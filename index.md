# Политика конфиденциальности приложения «Дневник СПб»

Дата вступления в силу: 19.10.2026

**Кто разработчик.** Приложение создано частным лицом: Genrikhs, контакт: a.genrikhs@yandex.ru. Приложение не является официальным и не связано с Комитетом по образованию Санкт-Петербурга, СПб ГУП «СПб ИАЦ», порталом «Петербургское образование» и «Госуслугами».

**Какие данные используются.** После входа приложение получает с портала «Петербургское образование» информацию об учебном процессе ребёнка: расписание, оценки, домашние задания, имя и класс. Эти данные нужны только для того, чтобы показать их вам в приложении.

**Вход.** Вход выполняется через «Госуслуги» на их официальной странице. Приложение не получает и не хранит ваш логин и пароль. Для работы сохраняется только сессия (cookie), которая выдаётся после входа.

**Где хранятся данные.** Данные ребёнка хранятся только на вашем устройстве. Сессия входа и сохранённые ответы портала зашифрованы ключом из Android Keystore. Отметки «выполнено» у домашних заданий не шифруются: в них только служебные номера заданий. Резервное копирование данных приложения отключено. Разработчик не получает данные ребёнка, не хранит их на своих серверах и не передаёт третьим лицам. Приложение не показывает рекламу и не использует сервисы аналитики.

**Отчёты о сбоях.** Чтобы узнавать о сбоях, приложение использует Firebase Crashlytics (Google LLC). При сбое или ошибке в Google уходят модель устройства, версии Android и приложения, технический журнал ошибки и случайный идентификатор установки. Имена, оценки, расписание, cookie и ответы портала в отчёты не попадают: текст ошибок вырезается до отправки. Google хранит отчёты до 90 дней ([конфиденциальность Firebase](https://firebase.google.com/support/privacy)).

**Куда отправляются запросы.** Приложение обращается к серверам портала «Петербургское образование» и «Госуслуг», чтобы выполнить вход и получить ваши данные, и к Firebase Crashlytics, чтобы отправить отчёт о сбое.

**Удаление данных.** При выходе из аккаунта приложение стирает с устройства сессию, сохранённые данные ребёнка, отметки домашних заданий, а также cookie, хранилище и кэш встроенного браузера. При удалении приложения стирается всё. Отчёты о сбоях Google удаляет сам, не позже чем через 90 дней.

**Дети.** Приложение предназначено для родителей и школьников. Разработчик не собирает данные детей.

**Изменения.** При изменении политики обновлённая версия будет опубликована на этой странице.
